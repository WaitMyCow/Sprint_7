# Sprint 7 — API-тестирование сервиса «Яндекс Самокат»

## Описание проекта

Проект посвящён автоматизированному тестированию API сервиса «Яндекс Самокат».

Цель — проверить корректность работы основных API-ручек, обработку успешных запросов и ошибок, а также соответствие ответов сервера требованиям API.

## Проверяемые эндпоинты

### 1. Создание курьера
- Успешное создание курьера.
- Проверка обязательных полей.
- Проверка создания двух курьеров с одинаковыми данными.
- Проверка создания курьера с уже существующим логином.
- Проверка HTTP-кодов и тела ответа.
- Проверка ответа `{"ok": true}` при успешном создании.

### 2. Авторизация курьера
- Успешная авторизация.
- Проверка обязательных полей.
- Проверка авторизации с неправильным логином или паролем.
- Проверка авторизации несуществующего пользователя.
- Проверка HTTP-кодов и тела ответа.
- Проверка наличия `id` в успешном ответе.

### 3. Создание заказа
- Создание заказа с цветом `BLACK`.
- Создание заказа с цветом `GREY`.
- Создание заказа с обоими цветами.
- Создание заказа без указания цвета.
- Проверка наличия `track` в ответе.
- Использование параметризации для проверки различных вариантов цвета.

### 4. Получение списка заказов
- Проверка успешного получения списка заказов.
- Проверка наличия поля `orders` в ответе.
- Проверка того, что значение `orders` имеет тип `list`.

## Запуск тестов

Установить зависимости:

```bash
pip install pytest requests allure-pytest
```

Запустить все тесты:

```bash
python -m pytest
```

Запустить тесты с формированием результатов Allure:

```bash
python -m pytest --alluredir=allure-results
```

Запустить отдельный файл:

```bash
python -m pytest tests/test_order_create.py
```

## Формирование отчёта Allure

Открыть отчёт:

```bash
allure serve allure-results
```

Сгенерировать отчёт в отдельную папку:

```bash
allure generate allure-results -o allure-report --clean
```

Открыть ранее сгенерированный отчёт:

```bash
allure open allure-report
```

Для работы команд Allure необходим установленный Allure Commandline и Java.

## Результаты тестирования

Результаты выполнения тестов сохраняются в директории `allure-results`.

Отчёт Allure содержит информацию о результатах тестирования, статусах тестов, группировке проверок и деталях выполнения.
